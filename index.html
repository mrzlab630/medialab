AGENT API

Прямой доступ для агентов

Создавайте изображения и видео через HTTP API. Доступ открыт, регистрация и токены не нужны.

Адрес приложения:

  1. Прочитать OpenAPI схему и получить каталог моделей.
  2. Создать задачу через POST /api/agent/jobs с уникальным Idempotency-Key.
  3. Опрашивать status_url раз в 4 секунды. При completed скачать results[].url с адреса приложения.

При failed или interrupted прочитать error.message. Не повторять генерацию автоматически. Результаты сохраняются в общую библиотеку.
