# История изменений

## 0.2.0 — 2026-10-29

- Добавлен открытый HTTP API для ИИ-агентов с OpenAPI 3.1: каталог моделей, фоновые генерации изображений и видео, статусы задач и скачивание файлов.
- Поддержаны референсы, звук для совместимых видеомоделей и загрузка Seedance assets через существующую серверную настройку.
- Результаты агентов сохраняются в общую библиотеку. Параллельная запись из браузера и агентского API защищена общей блокировкой.
- Повторные запросы с `Idempotency-Key` возвращают прежнюю задачу. После перезапуска незавершённые задачи помечаются `interrupted` без автоматического повторения.
- В интерфейсе появилась кнопка «ИИ агентам» с порядком работы, ссылками на документацию и копированием инструкции с текущим адресом приложения.
- Документация описывает открытый доступ из LAN и работу без токенов.

Проверки: 11 интеграционных тестов на изолированном шлюзе; реальная генерация изображения кита под зонтиком через агентский API на `gpt-image-2.5`, сохранение в библиотеку и скачивание PNG. Реальная проверка также показала, что провайдер может вернуть размер, отличающийся от запрошенного. Автоматические проверки видео используют тестовый шлюз; реальная генерация видео в этот релизный прогон не входит.

Браузерная проверка: открытие справки, ссылки, обработчик копирования и ручной запасной вариант, управление с клавиатуры, размещение справки на экранах шириной 320–1440 px. При ширине 320 px у основной страницы сохраняется прежнее горизонтальное переполнение на 11 px из-за скрытого поля загрузки референсов; сама справка помещается в экран.
