# История изменений

## 0.3.0 — 2026-10-29

- Карточки библиотеки открывают изображение или видео в отдельном окне с промптом, моделью, датой, фактическими размерами файла и сохранёнными настройками.
- Кнопка «Создать на основе этого» переносит промпт, тип, модель, формат, длительность и звук в форму без автоматического запуска генерации. Недоступная исходная модель отмечается в списке.
- Новые результаты браузера и агентского API сохраняют параметры генерации. Старые записи совместимы; отсутствующие настройки не подменяются догадками. Исходные референсы нужно добавить заново.
- Добавлена пагинация по 10, 30, 50 или 100 карточек, по умолчанию 10. Новая работа появляется на первой странице; добавление результата больше не обрезает историю до 50 записей.
- Удалена левая панель. Настройки подключения перенесены в верхнюю панель сразу после «ИИ агентам» и представлены иконкой ⚙.
- Во время загрузки моделей иконка ↻ вращается, повторные клики блокируются. При уменьшении анимации в настройках браузера используется изменение прозрачности.
- Вместо общего количества моделей показаны компактные счётчики ▧ и ▶ с подсказками для изображений и видео.

Проверки: 13 интеграционных тестов API; браузерные сценарии просмотра, переноса настроек, пагинации на 215 записях, добавления результата, пустой библиотеки, загрузки каталога, ошибок и повторного запроса. Генерации и изменения библиотеки в этих сценариях используют изолированные тестовые ответы; реальные запросы генерации к провайдерам в релизный прогон не входят.

Известное ограничение: при ширине 320 px у основной страницы сохраняется прежнее горизонтальное переполнение на 11 px из-за скрытого поля загрузки референсов. Новые окна и элементы пагинации помещаются в экран.

## 0.2.0 — 2026-10-29

- Добавлен открытый HTTP API для ИИ-агентов с OpenAPI 3.1: каталог моделей, фоновые генерации изображений и видео, статусы задач и скачивание файлов.
- Поддержаны референсы, звук для совместимых видеомоделей и загрузка Seedance assets через существующую серверную настройку.
- Результаты агентов сохраняются в общую библиотеку. Параллельная запись из браузера и агентского API защищена общей блокировкой.
- Повторные запросы с `Idempotency-Key` возвращают прежнюю задачу. После перезапуска незавершённые задачи помечаются `interrupted` без автоматического повторения.
- В интерфейсе появилась кнопка «ИИ агентам» с порядком работы, ссылками на документацию и копированием инструкции с текущим адресом приложения.
- Документация описывает открытый доступ из LAN и работу без токенов.

Проверки: 11 интеграционных тестов на изолированном шлюзе; реальная генерация изображения кита под зонтиком через агентский API на `gpt-image-2.5`, сохранение в библиотеку и скачивание PNG. Реальная проверка также показала, что провайдер может вернуть размер, отличающийся от запрошенного. Автоматические проверки видео используют тестовый шлюз; реальная генерация видео в этот релизный прогон не входит.

Браузерная проверка: открытие справки, ссылки, обработчик копирования и ручной запасной вариант, управление с клавиатуры, размещение справки на экранах шириной 320–1440 px. При ширине 320 px у основной страницы сохраняется прежнее горизонтальное переполнение на 11 px из-за скрытого поля загрузки референсов; сама справка помещается в экран.
