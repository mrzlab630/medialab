# Локальные данные и секреты

## Не публикуются

- `library/` содержит сгенерированные результаты, индекс библиотеки и промпты.
- `artifacts/` содержит результаты проб моделей, изображения, видео, ответы API и отчёты проверок.
- `.env*`, файлы ключей и сертификатов могут содержать секреты.
- `.playwright-mcp/`, `.centurion/` и `__pycache__/` содержат локальные данные инструментов и runtime.
- `localStorage` браузера хранит адрес шлюза и введённый API key; эти данные не являются файлами проекта.

Все перечисленные пути исключены в корневом `.gitignore`. Не снимайте эти исключения, чтобы отправить локальные медиа или секреты в общий репозиторий.

Также исключены распространённые форматы растровых изображений, аудио и видео вне этих каталогов. В репозиторий включён только исходный значок `favicon.svg`. `.gitignore` не проверяет содержимое исходников: случайно вставленный в код ключ нужно обнаружить до коммита. Параметры `git add -f` обходят исключения.

## Проверка перед публикацией

До каждого коммита просмотрите список файлов, которые будут отслеживаться:

```bash
git status --short
git diff --cached --name-only
```

Проверьте, что в подготовленный список не попали ключи, env-файлы, промпты, пользовательские референсы, медиа из библиотеки или содержимое `artifacts/`. Если секрет был закоммичен или отправлен, удаление файла из последующего коммита не отзывает его: ключ нужно заменить у поставщика.

## Настройка ключа загрузки Seedance

Сервер читает `APIAW_API_KEY` из переменной окружения `MEDIA_ASSET_API_KEY` или из файла, заданного `MEDIA_ASSET_ENV_FILE`. По умолчанию приложение смотрит во внешний файл `~/cliproxyapi/video-gateway.env`. Не копируйте этот файл в проект и не добавляйте его в Git.
